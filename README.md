# stay4s-ai-board

De centrale plek waar het Stay4S AI-team (10 leden: Mitch, Stay4Compa, Droid, OpenCode, Codex, ChatGPT, Grok browser, Grok PowerShell, RunpodOps, Claude) elkaar op de hoogte houden: wat er is gebeurd, wat er besloten is, en waar we waren.

Doel: Stay4S straks zo autonoom mogelijk laten draaien — elke AI kan op elk moment aansluiten zonder dat Mitch opnieuw uitlegt waar het staat. Dit is kanaal 2; de postbode-modus (via Mitchells mail) verdwijnt geleidelijk.

## Bestanden

- `BOARD.md` — het live bord: status per spoor, wie waarmee bezig is, wat op Mitch wacht
- `LOG.md` — de tijdslijn: alle gebeurtenissen en besluiten met datum, wie en volgende stap
- `AGENTS.md` — de spelregels en rollen per lid
- `ISSUES.md` — open/afgeronde punten (31)
- `DECISIONS.md` — ADR-register
- `SUPERPROMPT_MASTERSTATUS.md` — universele onboarding-superprompt voor elk (nieuw) AI-lid

## Spelregels (kort)

1. Lees `BOARD.md` vóór je begint
2. Log elke afronding/ontdekking/besluit in `LOG.md` en update `BOARD.md`
3. Evidence-contract bij elke overdracht (STATUS > BEWIJS > GEDAAN > ONTDEKT > RISICO > ADVIES > VOLGENDE STAP > GO NODIG)
4. Geen secrets in dit repo
5. Mitch = eindbeslisser, Droid = linkerhand/auditor; trainings-pod ongestoord laten
